# South Asian Nutrition Tracker
Program developed for my 13 Digital Technologies Assessment. It is a nutrition tracking program that is catered specifically for South Asians, bridging the evident gap in cultural representation in current nutrition tracking tools.

Author: Abhi Kaletla
Date: 5 Aug 2026
Purpose: My program will help South Asians track their nutrition without having to adapt to western focused nutrition tracking tools
A Python/Tkinter nutrition tracking application designed to help users track their nutritional intake and find South Asian recipes based on
their dietary preferences.

Instructions and important information:

#Requirements

- Windows 10 or later
- Python 3.x
- Internet connection for the initial installation
- Approximately 100 MB of free storage

#Installation

1. Install/Open Python
Make sure Python is added to PATH during installation.

2. Download this repository

Click the green "Code" button on GitHub and select "Download ZIP".
Extract the ZIP file.

3. Install the required library

Open Command Prompt or PowerShell and run:
pip install tkmacosx

4. Run the program
Open the downloaded project folder.

Open 'Tulamain.py' using IDLE, PyCharm, or another Python IDE.

Run 'Tulamain.py'
The nutrition tracker should open.

#Database

The repository contains 'nutrition.db' `nutrition.db`, which stores the meals,
recipes and logged meal information used by the program.

Do not delete or rename 'nutrition.db'

#Important

Do not run 'add_meals.py' unless you want to add the sample meals
to the database again, as this may create duplicate entries.

If the database isn't working, may need to create new data source and run database.py and add_meals.py again
